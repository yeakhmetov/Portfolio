# Источники котировок: что доступно

Отчёт к шагу 4 (сентябрь 2026). Проверено по открытым источникам; прямые запросы к сайтам бирж
и брокера из среды разработки были закрыты сетевой политикой, поэтому пункты, помеченные
**не проверено**, нужно подтвердить на реальном прокси.

## KASE — Казахстанская фондовая биржа

- **Официальный API — IRIS API** (`irisapi.kase.kz`, документация в формате OpenAPI и PDF на kase.kz).
  На нём работают веб-терминал IRIS и приложение KASE Mobile.
- **Доступ только по договору** с KASE («Для подключения к информационным продуктам KASE необходимо
  заключить типовой договор»). Отложенные данные — с задержкой **не менее 15 минут**, по подписке;
  стоимость не опубликована, уточняется в KASE (Service Desk +7 727 237 60 17).
- Открытого бесплатного API нет. Страницы котировок на kase.kz публичные, но условия их
  автоматического использования не опубликованы — парсинг сайта в приложение **не заложен**.
- **Вывод:** для частного инвестора реалистичный путь — данные брокера (ниже). Договор с KASE
  имеет смысл, если приложение станет публичным продуктом; тогда в прокси добавляется адаптер IRIS API.

## AIX — Astana International Exchange

- Торговая платформа — Nasdaq; рыночные данные распространяются через информационных вендоров.
- **Открытого API для частных лиц не найдено.**
- **Вывод:** котировки AIX — через API брокера, который торгует на AIX (Freedom, Halyk и др.).

## API брокера Freedom (Tradernet) — основной путь для KASE и AIX

- Клиенты Freedom Broker получают **публичный и секретный ключи API** в личном кабинете.
- Команда котировки: `quotes.getInfo` с параметром `ticker`; ответ содержит `l` (последняя цена),
  `curr` (валюта), `ltt` (время последней сделки). История: `quotes.getHloc`.
- Протокол v2: `POST <API>/v2/cmd/<команда>`, поля формы `apiKey`, `cmd`, `nonce`, `params[...]`,
  подпись HMAC-SHA256 от строки параметров, отсортированных по алфавиту, — в заголовке `X-NtApi-Sig`.
  Формат взят из открытой библиотеки [freedom-broker-api](https://github.com/MasyaSmv/freedom-broker-api)
  и реализован в `proxy/worker.js`, подпись проверена тестом.
- **Не проверено:** адрес API для клиентов Freedom Broker (Казахстан) — в прокси по умолчанию
  `https://tradernet.com/api`, меняется переменной `TN_API_URL`; суффиксы тикеров
  (`KCEL.KZ` для KASE, `KAP.AIX` для AIX) — меняются переменными `TN_SUFFIX_KASE`, `TN_SUFFIX_AIX`
  или своим обозначением у актива («Тикер для котировок»).
- Ключи хранятся только в секретах прокси, не в приложении и не в репозитории.
- Задержка данных зависит от тарифа брокера.

## Национальный банк РК — курсы валют

- Открытый RSS: `https://nationalbank.kz/rss/rates_all.xml` — официальные курсы на день
  (`title` — код валюты, `description` — курс, `quant` — за сколько единиц, `pubDate` — ДД.ММ.ГГ).
  Курсы на дату: `https://nationalbank.kz/rss/get_rates.cfm?fdate=ДД.ММ.ГГГГ`. Только https.
- CORS нет — идёт через прокси (`/fx`). Если прокси не настроен или недоступен, приложение берёт
  рыночный курс у запасного сервиса `open.er-api.com` (бесплатно, без ключа).

## Прочие источники (напрямую из браузера, прокси не нужен)

| Источник | Что | Ключ | Задержка |
|---|---|---|---|
| MOEX ISS (`iss.moex.com`) | акции, фонды, облигации Мосбиржи | не нужен | до 15 мин без подписки |
| CoinGecko (`api.coingecko.com`) | криптовалюты | не нужен (лимит ~30 запросов/мин) | ~1 мин |
| Twelve Data (`api.twelvedata.com`) | бумаги NYSE, NASDAQ, LSE, ETF | бесплатный ключ, 800 запросов/день | зависит от тарифа |
| open.er-api.com | курсы валют (запасной) | не нужен | обновление раз в день |

**Не проверено из среды разработки:** наличие CORS-заголовков у MOEX ISS. Если браузер их не получит,
MOEX можно будет добавить в прокси тем же способом.

## Порядок источников в приложении

| Биржа актива | Основной | Запасные |
|---|---|---|
| KASE | KASE (через брокера) | AIX → Twelve Data |
| AIX | AIX (через брокера) | KASE → Twelve Data |
| NYSE, NASDAQ | Twelve Data | KASE (сектор иностранных бумаг) |
| MOEX | MOEX ISS | — |
| Криптовалюта | CoinGecko | — |
| OTC, депозиты | вручную | — |

Если цена пришла в другой валюте (например, KAP на KASE в тенге для актива в долларах),
она пересчитывается по курсу. Если ни один источник не ответил, показывается последняя цена с датой.

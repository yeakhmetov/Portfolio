# Портфель

Мобильное приложение (PWA) для личного учёта инвестиционного портфеля:
акции, облигации, фонды, криптовалюта, депозиты и валюта. Котировки подтягиваются
автоматически с KASE, AIX и других источников, данные хранятся только на устройстве.

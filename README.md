# Портфель

Мобильное приложение (PWA) для личного учёта инвестиционного портфеля:
акции, облигации, фонды, криптовалюта, депозиты и валюта. Котировки подтягиваются
автоматически с KASE, AIX и других источников, данные хранятся только на устройстве.

Техническое задание для разработки — [PROMPT.md](PROMPT.md).

## Как запустить

**На телефоне.** Включите GitHub Pages для репозитория (Settings → Pages → ветка `main`, папка `/`),
откройте ссылку `https://<ваш-логин>.github.io/Portfolio/` и выберите «На экран «Домой»» (iPhone, Safari)
или «Установить приложение» (Android, Chrome). После первой загрузки приложение работает без интернета.

**Android-приложение (APK).** Свежая сборка всегда лежит по ссылке
[releases/download/android-latest/portfolio.apk](https://github.com/yeakhmetov/Portfolio/releases/download/android-latest/portfolio.apk):
откройте её на телефоне, скачайте и разрешите установку из этого источника. Обновления ставятся поверх,
данные сохраняются. APK собирается GitHub Actions ([.github/workflows/android.yml](.github/workflows/android.yml))
из тех же файлов, что и веб-версия, с помощью [Capacitor](https://capacitorjs.com); локально:
`npm ci && npm run android:sync`, затем `cd android && ./gradlew assembleRelease`.
Резервная копия и экспорт CSV в приложении сохраняются через меню «Поделиться».
Ключ подписи `android/app/portfolio-sideload.jks` лежит в репозитории — он нужен, чтобы обновления
ставились поверх, и подходит для личной установки.

**На компьютере.** Откройте `index.html` в браузере. Работа без интернета включается только при открытии
по адресу `http(s)://`, например: `python3 -m http.server` в папке проекта.

**Импорт из Excel.** «Ещё → Импорт из Excel-шаблона» загружает шаблон учёта брокерского счёта
(листы «Параметры», «Котировки», «Сделки», «Деньги», «Дивиденды»): операции выбранного счёта заменяются
историей из файла, остаток денег сверяется с выпиской, перед импортом показываются итог и XIRR на дату отчёта.
Образец структуры — [tests/fixtures/template-sample.xlsx](tests/fixtures/template-sample.xlsx).

Данные хранятся только на устройстве (IndexedDB). Резервная копия — раздел «Ещё» → «Сохранить копию».

**Котировки.** Криптовалюты (CoinGecko), бумаги Мосбиржи (MOEX) и запасные курсы валют работают сразу.
Для KASE, AIX и официальных курсов Нацбанка нужен небольшой прокси — [инструкция](proxy/README.md),
для бумаг NYSE/NASDAQ/LSE — бесплатный ключ Twelve Data. Что доступно у бирж — [docs/quotes-sources.md](docs/quotes-sources.md).

Тесты: `node tests.js` (расчёты, импорт, котировки) и `node proxy/test.mjs` (прокси), или откройте `tests.html`.

## Позиции по валютам

Вкладка «Позиции» делит бумаги на сегменты по валюте: тенговые и долларовые (и другие, если есть).
Над каждым сегментом — его стоимость и прибыль в своей валюте, у долларового рядом эквивалент в тенге;
сверху — общая стоимость всех позиций в тенге. Стоимость каждой бумаги показана в её валюте.

## Аналитика

Вкладка «Аналитика» показывает данные за выбранный период: этот и прошлый месяц, квартал, этот и прошлый год,
12 месяцев, всё время или свои даты; можно смотреть весь портфель или один счёт.

- Прирост портфеля и доходность за период (метод Дитца — без влияния пополнений и выводов), стоимость на начало и конец.
- Доходы: дивиденды, купоны (за вычетом налога), зафиксированная прибыль от продаж, комиссии, налоги — и сравнение с прошлым таким же периодом.
- График по неделям, месяцам или годам: выплаты, пополнения и выводы, прирост.
- Сделки за период, выплаты по бумагам с долями и список всех выплат по месяцам.

## Удобство (как в приложении «Расходы»)

- Подтверждения в шторке вместо системных окон; «Назад» закрывает шторку и выбор, возвращает на прошлую вкладку,
  на «Обзоре» после второго нажатия предлагает закрыть приложение. Открытая вкладка сохраняется при перезапуске.
- Долгое нажатие на операцию — выбор нескольких операций и удаление с отменой.
- В полях суммы, цены, комиссии и налога работает калькулятор: 1500×12+300.
- Нажатие на сектор диаграммы структуры показывает сумму и долю.
- «Ещё → О приложении»: версия и кнопка «Обновить».

## Безопасность

- PIN-код (4–6 цифр) хранится только как хэш SHA-256 с солью; после 5 ошибок — пауза от 30 секунд.
- Вход по отпечатку пальца / Face ID (в браузере — WebAuthn, в APK — нативный модуль); автоблокировка — от «сразу»
  до «никогда», кнопка «Заблокировать сейчас»; скрытые суммы показываются только после PIN-кода или отпечатка.
  PIN скрывает данные от посторонних, но данные на устройстве не шифруются.
- Ключи API и токен прокси хранятся только на устройстве и не попадают в резервную копию.
- Если PIN забыт, данные можно удалить и восстановить из резервной копии.

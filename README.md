# Портфель

Мобильное приложение (PWA) для личного учёта инвестиционного портфеля:
акции, облигации, фонды, криптовалюта, депозиты и валюта. Котировки подтягиваются
автоматически с KASE, AIX и других источников, данные хранятся только на устройстве.

Техническое задание для разработки — [PROMPT.md](PROMPT.md).

## Как запустить

**На телефоне.** Включите GitHub Pages для репозитория (Settings → Pages → ветка `main`, папка `/`),
откройте ссылку `https://<ваш-логин>.github.io/Portfolio/` и выберите «На экран «Домой»» (iPhone, Safari)
или «Установить приложение» (Android, Chrome). После первой загрузки приложение работает без интернета.

**На компьютере.** Откройте `index.html` в браузере. Работа без интернета включается только при открытии
по адресу `http(s)://`, например: `python3 -m http.server` в папке проекта.

Данные хранятся только на устройстве (IndexedDB). Резервная копия — раздел «Ещё» → «Сохранить копию».

**Котировки.** Криптовалюты (CoinGecko), бумаги Мосбиржи (MOEX) и запасные курсы валют работают сразу.
Для KASE, AIX и официальных курсов Нацбанка нужен небольшой прокси — [инструкция](proxy/README.md),
для бумаг NYSE/NASDAQ/LSE — бесплатный ключ Twelve Data. Что доступно у бирж — [docs/quotes-sources.md](docs/quotes-sources.md).

Тесты: `node tests.js` (расчёты, импорт, котировки) и `node proxy/test.mjs` (прокси), или откройте `tests.html`.
